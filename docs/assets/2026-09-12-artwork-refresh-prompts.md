# Website artwork refresh prompts

Created 12 September 2026 using OpenAI's built-in image-generation tool in
Codex. The tool does not expose its underlying model identifier, so this
record makes no model-version claim.

These prompts remake the six presentation images used by the website. Each
initial generation used the corresponding original generated image from
repository commit `5d1ef76998b7dd1fa2946462179402d37d11c5b3` as its sole image
reference. A directed follow-up, where recorded, used that first result as
its reference. No third-party source image was used.

All images are non-canon presentation artwork. Earlier prompts remain in
[ARTWORK.md](ARTWORK.md), [edravoss-world-prompts.md](edravoss-world-prompts.md)
and [world-life-prompts.md](world-life-prompts.md).
