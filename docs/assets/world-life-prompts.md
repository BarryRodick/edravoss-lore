# World and everyday life artwork prompts

Created 4 September 2026 with OpenAI's built-in image-generation tool. These
prompts accompany the revised world image, revised warning wall and new basin
home scene. All are non-canon presentation artwork.

The world edit uses the preceding repository version of `edravoss-world.jpg`
at commit `21bde2f` as its original generated source. Earlier prompts remain in
`edravoss-world-prompts.md`. The wall edit uses `road-speech-wall.jpg` from the
same commit; its original generation prompt remains in `ARTWORK.md`.
The home scene is generated without an input image.

Cold diffuse daylight outdoors, restrained warm oven light under the gallery. Charcoal, peat brown, muted moss green, cloth rust-red and weathered gold. Enough light to see expressions and materials.
